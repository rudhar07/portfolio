# Portfolio — Rudhar Bajaj

A 3D, table-tennis-themed personal portfolio. Black + red rubber palette, a ball that drops and gets struck in a GSAP cinematic, a broadcast-style scoreboard that tracks your scroll, and sections framed as a tournament rally.

## Stack

- **React + Vite**
- **React Three Fiber + Drei** — 3D scene, HDR environment lighting, GLTF loading
- **Rapier** — physics for the ball (gravity, bounce, impulse)
- **GSAP + ScrollTrigger** — cinematic timeline and scroll-driven animations
- **Lenis** — smooth scroll
- **Howler** — audio (the *pock*)

## Run locally

```bash
npm install
npm run dev
```

Then open the URL Vite prints (usually `http://localhost:5173`).
